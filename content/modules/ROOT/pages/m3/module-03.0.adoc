== 개요

{product_name_rhdh}의 소프트웨어 템플릿을 활용하면 팀이 컴포넌트를 생성하고, (플러그인이 제공하는 "actions"을 통해) GitLab 및 OpenShift GitOps 인스턴스와 같은 다른 시스템에서 리소스를 만들 수 있습니다. 각 템플릿은 엔터티(Entity)로 저장되므로 다른 엔터티와 마찬가지로 가져올 수 있습니다.

플랫폼 엔지니어는 일반적으로 템플릿의 작성자이며, 모범 사례를 따라 승인된 프로세스 및 도구를 사용하는 "golden path"를 템플릿으로 구축합니다. 개발 팀은 이 템플릿을 활용하여 새로운 소프트웨어를 만듭니다. 이를 통해 플랫폼 관련 사항은 템플릿이 처리하고 개발자는 개발 작업에 집중할 수 있어 인지적 부담을 줄일 수 있습니다.

템플릿은 YAML로 정의되지만, 개발 팀이 사용할 때에는 {product_name_rhdh} UI에서 리치 폼(Rich Form) 형태로 표시됩니다.

== 모듈 목표

* 템플릿 생성 (플랫폼 엔지니어 역할)
* 소프트웨어 카탈로그에 템플릿 등록 (플랫폼 엔지니어 역할)
* 템플릿을 활용하여 새로운 컴포넌트, GitLab 저장소, GitOps 애플리케이션 생성 (개발자 역할)
